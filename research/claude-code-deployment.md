# Claude Code deployment reference for the prompt pack (verified 2026-10-18 against code.claude.com and platform.claude.com by a claude-code-guide research agent)

## Summary
1. Subagents live in `.claude/agents/<name>.md`. Only `name` and `description` are required. `model` accepts `sonnet`, `opus`, `haiku`, `fable`, a full ID (`claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5` confirmed on the platform models page), or `inherit`. `effort` IS supported in frontmatter (`low|medium|high|xhigh|max`).
2. Subagents can spawn subagents 3 layers deep by default (`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`). Max 20 run concurrently (`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`). Subagents load CLAUDE.md but not the conversation; their final message returns to the caller.
3. Opus 5.5 defaults to effort `medium`. Thinking cannot be turned off on Opus 5.5 / Sonnet 5.5 / Haiku 5.5. Set effort explicitly for the architect.
4. Package the master prompt as a skill (`.claude/skills/architect/SKILL.md` with `disable-model-invocation: true`, run as `/architect`), not in CLAUDE.md. Keep CLAUDE.md under 200 lines. After compaction only the first ~5,000 tokens of an invoked skill are re-attached (fetch summary, not verbatim) → put non-negotiables first.
5. Claude Code reads AGENTS.md directly from v2.1.277, but only when no CLAUDE.md exists in the working directory or above. Otherwise import it with `@AGENTS.md` from CLAUDE.md.
6. `claude -p` supports `--model`, `--effort` (incl. `ultracode`), `--max-turns`, `--max-budget-usd` (client-side estimate), `--output-format json|stream-json`, `--permission-mode`, `--agents` (inline JSON or file), `--append-system-prompt-file`, `--resume`. `--bare` skips CLAUDE.md, agents, hooks, skills and requires `ANTHROPIC_API_KEY`.
7. SDK option names are camelCase (TS) / snake_case (Python). `AgentDefinition` has no `hooks` field. If `settingSources` is omitted, user/project/local sources load (CLAUDE.md, skills, agents).
8. `Stop` and `SubagentStop` hooks with exit 2 or `"decision":"block"` keep the agent working; check `stop_hook_active` to avoid loops. A `PreToolUse` hook with matcher `Write|Edit` can block bad spec writes (structure only, not truth).
9. The Workflow tool ("dynamic workflows" in docs) suits fan-outs: 16 concurrent by default (`CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS`, up to 256), 1,000 agents per run, scripts saveable under `.claude/workflows/` and run as `/<name>`. In `-p` it needs a `Workflow` allow rule. Per-agent model/effort options for `agent()` were NOT shown in the public pages (UNVERIFIED there; this session's own Workflow tool exposes `model`/`effort`/`agentType` opts).
10. Opus 5.5: 128K max output per response, 1M context. No per-Write size limit documented → chunk long spec files. API price Opus 5.5 $4/$20 per MTok. Max plan from $100/month (5x/20x Pro) in rolling 5-hour + weekly windows; `-p` and SDK runs do not pause at usage limits, they fail → plan `--resume`.

## 1. Subagent definition files
Locations (highest priority first): managed settings; `--agents` JSON (session only); `.claude/agents/` (project; searched from cwd up to repo root, recursive); `~/.claude/agents/`; plugin `agents/`. Filename need not match `name`. Edits apply without restart.
Frontmatter (https://code.claude.com/docs/en/sub-agents.md): `name` (required, ≤256 chars, no ":"), `description` (required; drives automatic delegation; "use proactively" encourages it), `tools` / `disallowedTools` (comma string or YAML list; omit to inherit all), `model` (`sonnet|opus|haiku|fable|<full id>|inherit`), `effort` (`low|medium|high|xhigh|max`; overrides session level, not `CLAUDE_CODE_EFFORT_LEVEL`), `permissionMode` (`default|acceptEdits|auto|dontAsk|bypassPermissions|plan`; main session's bypass/acceptEdits/auto wins), `maxTurns` (partial output on limit, resumable v2.1.246+), `autoCompactWindow` (100000–1000000, v2.1.296+), `skills` (preloaded), `mcpServers`, `hooks` (scoped; ignored for plugin subagents), `memory` (`user|project|local`), `background: true`, `isolation: worktree`, `initialPrompt`, `omitClaudeMd: true` (v2.1.271+), `color`, `experimental.cacheTtl` (`5m|1h`, v2.1.248+).
Model resolution: per-invocation param → frontmatter `model` → `CLAUDE_CODE_SUBAGENT_MODEL` → main model. `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1` overrides frontmatter.
Alias targets differ by provider (model-config page): Anthropic API opus=Opus 5.5, sonnet=Sonnet 5.5, haiku=Haiku 5.5; Bedrock/Google Cloud opus=Opus 5.5, sonnet=Sonnet 4.5, haiku=Haiku 4.5; Foundry opus=Opus 4.6, sonnet=Sonnet 4.5. **Pin full IDs.**
Effort per agent: frontmatter `effort`; per-invocation effort param for non-fork subagents (v2.1.292+). Subagents inherit the session's thinking state; no per-subagent thinking field.
CLAUDE.md inheritance: non-fork subagents load the full CLAUDE.md hierarchy (managed, ~/.claude/CLAUDE.md, project, CLAUDE.local.md, AGENTS.md where applicable). Explore and Plan skip it. Subagents do not see conversation history; the delegation prompt is their task.
Invocation: Agent tool (renamed from Task in v2.1.63 per fetch summary); automatic delegation by description; @-mention; `claude --agent <name>`; `"agent"` setting. Combined description budget 15,000 tokens.
Nesting/concurrency: depth 3 below main (v2.1.219+); 20 concurrent; no total cap.
Background: fork mode default on interactively (v2.1.232+), off in `-p`/SDK. Background subagents get a reduced built-in tool set plus MCP tools; results arrive as a completion notification. In `-p` the run stays open until background subagents finish.
Minimal example:
```
---
name: spec-reviewer
description: Reviews one spec section for unsourced or unverified factual claims. Use proactively after any spec file is written or changed.
tools: Read, Grep, Glob, WebFetch
model: claude-opus-5-5
effort: high
maxTurns: 30
---
You review one spec section. For every factual claim, confirm a source line of the form [src: <url> @ <YYYY-MM-DD>] is present and supports it. Return findings ordered by severity. Do not edit files.
```
`--agents` JSON uses `prompt` for the body and omits `color`/`experimental`.

## 2. Skills and packaging
SKILL.md frontmatter (https://code.claude.com/docs/en/skills.md): `name` (defaults to dir name), `description`, `when_to_use`, `argument-hint`, `arguments`, `disable-model-invocation` (true = only the user can invoke; blocks subagent preloading), `user-invocable` (false = Claude-only), `allowed-tools`, `disallowed-tools`, `model`, `effort`, `context: fork` with `agent` and `background`, `hooks`, `paths`, `shell`. Unknown fields ignored. description + when_to_use truncated at 1,536 chars in the listing. Keep SKILL.md under 500 lines; move detail into supporting files. Substitutions: `$ARGUMENTS`, `$N`, named arguments. Locations: enterprise, `~/.claude/skills/<name>/SKILL.md`, `.claude/skills/<name>/SKILL.md`, nested subdirectory skills, plugin skills.
Options: CLAUDE.md (always loaded, not enforced; short always-true conventions only; procedures belong in skills) · Skill with `disable-model-invocation: true` (best fit; `/architect` interactively or `claude -p "/architect spec/brief.md"`) · `.claude/commands/` (unification with skills UNVERIFIED) · plain first message (not reproducible) · `--agent` as main thread (body replaces the default system prompt; add `--append-system-prompt-file` if used).
Recommendation: master prompt = `.claude/skills/architect/SKILL.md` (+ `phases.md`, `templates.md` supporting files; non-negotiables in the first 5,000 tokens); 13 workers = `.claude/agents/*.md`; spec-format rules = `.claude/rules/spec.md` with `paths: ["spec/**/*.md"]`; CLAUDE.md = commands + the source-citation rule + pointer to the skill, under 200 lines.
Example SKILL.md:
```
---
name: architect
description: Runs the multi-agent architecture pass and writes the build spec.
disable-model-invocation: true
argument-hint: "<brief-path>"
effort: max
---
Read the brief at $ARGUMENTS. Follow [the phases](phases.md) in order. Delegate each worker role to its named subagent. Write outputs to spec/. Read [templates](templates.md) before writing any spec file.
```

## 3. CLAUDE.md and AGENTS.md (https://code.claude.com/docs/en/memory.md)
Load order: managed policy → `~/.claude/CLAUDE.md` → `./CLAUDE.md` or `./.claude/CLAUDE.md` → `./CLAUDE.local.md`; cwd + ancestors load at launch; subdirectory files load on demand. Size: "target under 200 lines per CLAUDE.md file"; imports do not reduce context cost (imported files load at launch). Imports: `@path/to/file` relative to the importing file, max depth 4 hops; imports inside code spans/fences are skipped; outside-working-dir import triggers approval dialog. Block-level HTML comments are stripped (free maintainer notes). CLAUDE.local.md is personal/gitignored. `.claude/rules/*.md`: loaded at launch without `paths`; with `paths` only when a matching file is read/edited. Auto memory: first 200 lines / 25KB load every session. `/doctor prompt-audit` (v2.1.283+) checks instruction files. `claudeMdExcludes` skips ancestor files in monorepos.
AGENTS.md: read directly from v2.1.277 only when no CLAUDE.md / CLAUDE.local.md / .claude/CLAUDE.md exists in cwd or above; otherwise ignored unless imported. AGENTS.local.md / AGENTS.override.md are not read. Adding CLAUDE.local.md disables the direct read unless "Project instructions" is set to claude-md-and-agents-md.

## 4. Headless and Agent SDK
CLI (https://code.claude.com/docs/en/cli-reference.md, /headless.md): `--model`; `--effort low|medium|high|xhigh|max|ultracode` (ultracode v2.1.203+); `--max-turns` (error when reached); `--max-budget-usd` (client-side estimate; subagent spend counts); `--output-format text|json|stream-json` (stream-json needs `--verbose`; `--include-partial-messages`); `--input-format`; `--json-schema`; `--permission-mode default|acceptEdits|plan|auto|dontAsk|bypassPermissions|manual`; `--permission-prompts none` (v2.1.259+); `--allowedTools/--disallowedTools/--tools`; `--agents` (inline JSON or file path with -p, v2.1.281+); `--agent <name>`; `--append-system-prompt(-file)`, `--system-prompt-file`, `--append-subagent-system-prompt-file` (v2.1.261+); `--continue/-c`, `--resume/-r <id|name|jsonl>`, `--fork-session`, `--session-id`; `--bare`. Exit 0 success; SIGTERM 143.
Example: `claude -p "/architect spec/brief.md" --model claude-opus-5-5 --effort max --max-turns 300 --max-budget-usd 150 --permission-mode dontAsk --allowedTools "Read,Grep,Glob,Write,Edit,Agent,Workflow,Bash(git status *),Bash(git diff *)" --append-system-prompt-file spec/house-rules.txt --output-format stream-json --verbose` (placeholder values).
Agent SDK (https://code.claude.com/docs/en/agent-sdk/typescript.md, /python.md): options model/fallbackModel/effort/thinking(TS)/maxTurns/maxBudgetUsd/permissionMode/allowedTools/disallowedTools/tools/agents/agent/hooks/systemPrompt/settingSources/cwd/canUseTool/includePartialMessages/resume/continue/env (camelCase TS, snake_case Python). `AgentDefinition`: description, prompt, tools, disallowedTools, model, skills, memory, mcpServers, initialPrompt, maxTurns, background, effort, permissionMode (+ autoCompactWindow, omitClaudeMd in TS); no hooks field (use query-level hooks; input carries agent_id/agent_type). `settingSources` omitted → user/project/local load. `canUseTool` returning null blocks indefinitely (TS). ResultMessage subtypes: success, error_during_execution, error_max_turns, error_max_budget_usd, error_max_structured_output_retries; fields subtype, is_error, result, num_turns, session_id, total_cost_usd.
Python sketch: `ClaudeAgentOptions(model="claude-opus-5-5", effort="max", max_turns=300, max_budget_usd=150.0, permission_mode="dontAsk", allowed_tools=[...], setting_sources=["project"], agents={"spec-reviewer": AgentDefinition(description="...", prompt="...", model="claude-opus-5-5", effort="high")})` then `query(prompt="/architect spec/brief.md", options=options)` (slash-prompt route in SDK UNVERIFIED).

## 5. Hooks (https://code.claude.com/docs/en/hooks.md)
Events include SessionStart, UserPromptSubmit, PreToolUse, PermissionRequest, PostToolUse, PostToolUseFailure, SubagentStart, SubagentStop, TaskCreated, TaskCompleted, Stop, PreCompact, PostCompact, SessionEnd and others. settings.json shape: `{ "hooks": { "PostToolUse": [ { "matcher": "Edit|Write", "hooks": [ { "type": "command", "command": "/path/to/lint-check.sh" } ] } ] } }`. Handler types: command, http, mcp_tool, prompt, agent (timeouts 600s/600s/600s/30s/60s). Exit 0 success (stdout JSON parsed); exit 2 blocking error with stderr fed to Claude; others non-blocking. Decision control: `"decision":"block"` + `"reason"`; PreToolUse `hookSpecificOutput.permissionDecision: allow|deny|ask|defer`. Stop input: stop_hook_active, last_assistant_message, background_tasks, session_crons; exit 2/block continues the turn; loop cap 8 consecutive continuations. SubagentStop input: stop_hook_active, agent_id, agent_type, agent_transcript_path, last_assistant_message. PreToolUse input: tool_name, tool_input (Write: file_path, content; Edit: file_path, old_string, new_string, replace_all), tool_use_id.
Example settings: Stop → `tests-before-done.sh` (reads stdin JSON; if stop_hook_active true exit 0; run `npm test`; on failure echo reason to stderr and exit 2). PreToolUse matcher `Write|Edit` → `spec-source-check.sh` (for `*/spec/07-milestones/*.md` reject content containing UNVERIFIED inside acceptance criteria; structure only, not truth). `/goal` is a built-in session-scoped prompt-based Stop hook. TaskCompleted example exits 2 when `npm test` fails.

## 6. Plan mode, Workflow tool, output limits
Plan mode (permission-modes.md): read-only exploration + plan; edits blocked until approval; `--permission-mode plan`; `"defaultMode": "plan"`; subagent `permissionMode: plan`; approval requires an interactive session; how a `-p` plan run ends is UNVERIFIED.
Workflow tool (workflows.md): JS script orchestrating subagents in background; saveable under `.claude/workflows/`, runnable as `/<name>`; paid plans/API/Bedrock/Google/Foundry (Pro: enable in /config); functions agent(prompt, {schema,label,stallMs}), pipeline(), parallel(), phase(), log(), `args`; limits 16 concurrent default (env up to 256), 4,096 items per call, 1,000 agents per run; no FS/shell/import in the script; relaunch returns saved results; stalled agents retry ≤5; `-p`/SDK need a `Workflow` allow rule; large-workflow warning above 25 agents or 1.5M projected tokens (advisory).
Output limits: Opus 5.5 / Sonnet 5.5 / Haiku 5.5 128K max output, 1M context (platform models overview). `CLAUDE_CODE_MAX_OUTPUT_TOKENS` default varies (unrecognized ids: 32000 default, 128000 cap; Opus 5.5 default UNVERIFIED). Write overwrites full content; chunk long files (skeleton + Edit appends). Bash inline output ≈30,000 chars (10,000 on failure); `BASH_MAX_OUTPUT_LENGTH` up to 150,000; `bashOutputMaxChars` up to 128,000 (v2.1.261+). Have workers write artifacts to files and return short summaries.

## 7. Cost and rate considerations (costs.md, platform models overview, claude.com/pricing)
API per MTok: Opus 5.5 $4/$20; Sonnet 5.5 $2/$10; Haiku 5.5 from $0.10/$0.50; Fable 5.1 $10/$50; cache reads 5% of base input on Opus 5.5 / Sonnet 5.5. Subscriptions (as fetched): Pro $17 annual/$20 monthly; Max from $100/month (5x/20x); Team Standard $20/$25, Premium $100/$125; Enterprise $20/seat (20-seat min) + usage at API rates. Rolling 5-hour + weekly limits; claude.ai and Claude Code share one pool. Enterprise averages: ≈$13/developer/active day; $150–250/developer/month; 90% under $30/day — not benchmarks for multi-hour architect runs. Interactive sessions can auto-continue at usage limit (autoContinueAtUsageLimit, within 24h, two waits max); `-p`/SDK/background/Remote Control do not pause → fail → plan `--resume`. Cache lifetime: 1h for subscription main session; 5m for API keys/cloud; Workflow subagent caches 5m by default even on subscriptions (`subagentPromptCacheTtl: "1h"`). `--max-budget-usd` is an estimate but still stops the run. No docs guidance specific to multi-hour Opus runs.
