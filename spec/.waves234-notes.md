# Binding notes for Waves 2–4 (Architect, after Wave 1 reconciliation, 2026-10-18)

Shared context is v1.0 and FROZEN. These notes summarize the exact names, paths and fields Wave 2–4 subagents must use. Corrections after the independent contract check are DL-051…DL-076 in `spec/11-decision-log.md` (notably DL-053: every cross-domain asset reference is a full C07 `AssetRef` `<kind>/<id>`).

1. Read prompt-pack/06-SHARED-CONTEXT.md v1.0 (frozen) §4.2–4.4 and §5, spec/11-decision-log.md (DL-001…050) and spec/02-architecture.md §7. Frozen contracts are never edited: put changes in `contract_change_proposals`.
2. Tiers: only C13 `QualityTierId` = desktop-ultra|desktop|mobile|mobile-low|xr-quest|xr-visionpro (packages/shared/src/platform/c13.ts). Variants resolve via `VARIANT_FALLBACK`; budgets come from config/tier-budgets.json.
3. Sim: SIM_DT 1/60; AI at 30 Hz on every tier (AI_DIVISOR 2); netOut 20 Hz. Modes reach the engine only through C06 `ModeContext` (packages/shared/src/contracts/c06-modes.ts: GameModeDescriptor, GameModeSim, PursuitApi, ZoneService, SimScheduler 2,000 ops/thread/tick, EconomyApi in integer cents). Sim code obeys the C02 lint (no Math.random, Date, three or DOM).
4. Persistent ids: C01 `StableKey` (`amb:<cellKey>:<slot>`, `npc:<id>`, `mis:<missionId>:<name>`, `veh:<id>`), never EntityId. Component id ranges: world 256–511, story 512–767, npc 768–1023, racing 1024–1279, fighter 1280–1535, tycoon 1536–1791, mod 2048–4095.
5. Saves: C05 `SlotId` = core|settings|sandbox|story:auto|1|2|3|mode:racing|fighter|tycoon|mod:<id>, with one SaveRecord per slot. Mode slices use `GameModeDescriptor.saveSlot` = `mode:<id>`. Mission checkpoints are `{schema,data}` in `StorySlice.activeMission`. `ProfileSettings.xr = XrComfortSettings & {heightCalibM}`. Device settings and telemetry consent live in S11 `PlatformSettings` (IndexedDB dv-platform), never in C05.
6. Input: `SimButton` bits 0–15 are the net set; any new sim bit (≥ 19) is local-only. Use `InputContextId` and `DeviceKind`; pose input arrives as C03 `PoseActionEvent`. Camera: sim publishes `CameraDirective`/`CinematicShot`; XR is `immersive-vr` only.
7. Animation: skeleton `bay_rig_v1` with C04 `HUMANOID_BONES`. Network anim is u8 `AnimStateId`; S06/S07/S08 claim blocks in 128–255 by ADR.
8. Assets (C07): `AssetRef` `<kind>/<id>`, AssetId `^[a-z0-9][a-z0-9._-]{1,62}$`, keys `<root>/<variant>.<sha256[0:12]>.<ext>`. Character-derived kinds require `likeness` and `tags:['char:<npcId>']`; every shipped file has a ProvenanceRecord; world packs are kind `world_pack` (≤ 4 MiB); the catalog pointer is /asset-catalog.json.
9. S02/C08: chunk key is a `z/x/y` string; ENU frame at City Hall (+X east, +Y up, −Z north). Ship config/world.bounds.json. Chunk tags: hidingSpots, pursuitBreakers, chokePoints, jumpZones, portals, shoreNodes, teleportNodes. Spawn tables keyed `(cellKey, slot)` with `densityCap` (tier prefix rule). Per chunk: ≤ 6 render objects in one BundleGroup, `static=true`, a shared heightfield and a StaticShapeSet; ≤ 1 chunk upload per frame.
10. S03/C09: compute the cache key with packages/shared/src/genai and `canonicalize` (A-03). Status comes from GET /api/v1/cutscenes/:key → CutsceneStatus (ready|pending|absent|failed|blocked). The ready signal is cutscenes/<key>/manifest.json, written last (v540/v768/v1080, a.m4a, poster.webp, last.webp, subs.<lang>.vtt, characters[{id,soulVersion,tier}], licence). Build the release cutscene-index (with S05 tools/assets). CutscenePlayer uses S11 FirstGestureUnlock and XrMediaHost, and the in-engine fallback always exists.
11. S04/C10: soulVersion is an integer; soul id = asset slug; assets.rig = rig/bay_rig_v1. `NPCDialogueRequest {npcId, encounterId?, soulVersion, turn:{text?,intent?}, context, maxTokens}` carries no history[]. SSE events: meta, line.delta, line.done, effects{action?,mood?,memoryWrite?}, fallback, done. First token within 4 s, else fallback. The prompt prefix lives in PRIVATE souls/<id>/<ver>/soul.prompt.txt. Kill-switch via RosterFlags/KillScope (C12 route 30).
12. S12/C14/C17: expose `modsActive(): boolean` (rooms close 4007). `permissions[]` is a closed enum, and each asset carries a C07 ProvenanceRecord. Mod saves use `mod:<id>` slots only. Anchor `{lat,lng,chunkKey}`, radius ≤ 250 m; moderation and visibility are server-owned. Routes 35–37 (list/publish), 36 needs P2 with the `mods:publish` device token.
13. API (C12): only /api/v1/* routes #1–49 (09-backend-contracts.md §2.4), errors as ApiError; quota_exhausted, budget_offline, kill_switched and upstream_unavailable select the offline fallback. Ids are UUIDv7 and times epoch ms. genAI money is integer USD micros. Identity profileId (UUIDv7) is not the C05 save ProfileId (32-hex).
14. Telemetry (C16): emit only TelemetryName registry names via the packages/engine/src/platform/telemetry client and propose new names in the return block. Never send free text, profile ids or positions finer than a chunkKey.
15. Rooms (C11): mode multiplayer goes through ACT JoinActivity/LeaveActivity and EV Activity (data ≤ 768 B). Speed caps live in config/net.speedcaps.json (S06 tunes).
16. Platform: XR per-mode rules in 11-platform-xr.md §5.3; S10 provides `UiSurface` for XR panels (DN-S11-03) and calls `PwaUpdateController.markSafePoint`; XR comfort type is `XrComfortSettings`.
17. Names: packages `@dv/<dir>`, modes `@dv/mode-<id>` at packages/modes/<id>. Scripts `pnpm check:*` (check:unit, check:e2e -- --project=<p> --grep @tag, check:perf, check:workers, check:assets …). Playwright projects: chromium-webgpu, chromium-webgl2, webkit-webgl2, xr-quest3. Storage prefix `dv-`, config in config/, QA flag `VITE_DV_QA`.
18. Milestone ids come from the register in spec/00-plan.md (M00/M00b/M00c, M01a–e, M04a–c, M05a–d, M12a–c, M13a–d, …): letter = scope, digit = session split.
