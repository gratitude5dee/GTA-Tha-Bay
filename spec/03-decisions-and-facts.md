**R2 media through a Worker (Architect-verified 2026-10-20, DL-713).** (1) The R2 Workers binding offers `head(key)` and `get(key, options)`. `get` accepts `onlyIf` and `range` as request `Headers` (or as objects), returns `null` for a missing key and an `R2Object` without `body` when a precondition fails. `writeHttpMetadata(headers)` copies the stored HTTP metadata, and `httpEtag` is the quoted ETag to send (https://developers.cloudflare.com/r2/api/workers/workers-api-usage/, https://developers.cloudflare.com/r2/api/workers/workers-api-reference/). (2) With static assets, navigation requests (`Sec-Fetch-Mode: navigate`) prefer asset serving by default from compatibility date 2025-04-01 (flag `assets_navigation_prefers_asset_serving`), so with `not_found_handling: "single-page-application"` an unmatched navigation gets `index.html` without invoking the Worker. An array form of `assets.run_worker_first` names the paths that invoke the Worker first and opts out of the `Sec-Fetch-Mode` handling; it needs Wrangler 4.20.0 or later (https://developers.cloudflare.com/workers/configuration/compatibility-flags/, https://developers.cloudflare.com/workers/static-assets/routing/single-page-application/). (3) Cache API operations are documented as working on Workers deployed to custom domains and as having no impact in the dashboard editor and Playground; the page does not list `workers.dev` among working cases (https://developers.cloudflare.com/workers/runtime-apis/cache/). Workers Caching (`cache.enabled` in the Wrangler file) can run on `workers.dev`, is keyed by path, entrypoint, `ctx.props` and Worker version rather than hostname, sits in front of every entrypoint unless one disables it per entrypoint, and needs Wrangler 4.69.0 or later (https://developers.cloudflare.com/workers/cache/, https://developers.cloudflare.com/workers/cache/examples/, https://developers.cloudflare.com/workers/cache/debugging/). (4) Prices: Workers Paid (Standard) includes 10 million requests a month, then $0.30 per million, and 30 million CPU ms, then $0.02 per million ms; requests to static assets are free (https://developers.cloudflare.com/workers/platform/pricing/). R2 Standard Class B operations: 10 million a month free, then $0.36 per million; egress free (https://developers.cloudflare.com/r2/pricing/).

**Playwright test timeouts and retries (Builder-verified 2026-10-23, BD-FIX-CI7-F03).** (1) "Time spent by the test function, fixture setups, and `beforeEach` hooks is included in the test timeout", which is 30 seconds by default [https://playwright.dev/docs/test-timeouts, read 2026-10-23]: a slow `newContext` (the `context` fixture) uses up the budget of the test that asks for it. (2) After a test fails, Playwright "will discard the entire worker process along with the browser and will start a new one", and the retry runs first in that new worker [https://playwright.dev/docs/test-retries, read 2026-10-23]: a retry never shares a browser with the attempt before it. (3) Measured here, not documented: on the `chromium-webgpu` launch flags (`--enable-features=Vulkan --use-angle=swiftshader --use-vulkan=swiftshader`), Chromium 156 headless gives a WebGL page no frame back-pressure, and after a context with such a page closes, the next `Target.createBrowserContext` waits until the GPU process has drawn the queued frames (10 to 65 s for a 10 s page under load; about 0.1 s without the flags).

**Wrangler local secrets come from the process environment (Builder-verified 2026-10-23, BD-FIX-CI8-H02).** With a `secrets` property in the Wrangler configuration, local development loads the keys listed in `secrets.required` from `.dev.vars` or `.env`, and the `secrets` property "loads from `process.env` automatically" (no `CLOUDFLARE_INCLUDE_PROCESS_ENV` needed); keys not listed are left out, and a missing key only warns [https://developers.cloudflare.com/workers/configuration/secrets/, read 2026-10-23].
