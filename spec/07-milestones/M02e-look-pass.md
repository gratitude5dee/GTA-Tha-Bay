# M02e — look-pass

## Goal
After this session the streamed city stops looking like flat-coloured boxes under flat light. The same baked geometry from M02b1 gets TSL physically based materials: procedural façades per building class (a floor and window grid from the building's height, per-class palette and roughness, glass, night windows driven by M02b2's clock), roof materials by roof type, and ground, sidewalk, asphalt, park and water surfaces (water with simple TSL waves). On the desktop tiers a physically based day sky and sun follow M02b2's hour and weather. The renderer gets a real post stack built from the C13 `TierFeatures` data, which no milestone wired so far: tone mapping and exposure on every flat tier; GTAO at half resolution, bloom, SMAA or TRAA and cascaded sun shadows on `desktop` and `desktop-ultra`; FXAA and one near shadow cascade on `mobile`; tone mapping only on `mobile-low`. XR tiers keep the M02b1/M02b2 look. The M01c perf gates stay green at every tier, deterministic 256 px screenshot goldens at fixed time and weather run on `chromium-webgl2`, and a before/after image is committed under `docs/look/` (DL-704). Landmark models stay in M02d1–M02d2 and sourced art (facade atlas, skyline cards, `desktop-ultra` atmosphere) in M10d1–M10d3.

## Requirements
- R-MAP-01: buildings, streets, parks and the waterfront read as a city at street level: class-specific façades, roofs and ground materials instead of flat colours.
- R-MAP-04: day/night and weather change the light: sun colour and shadows from the hour, exposure from the sky keys, lit windows at night, wet asphalt.
- R-PLAT-03: the post stack and every material run on one `WebGPURenderer` in TSL, on WebGPU and on the WebGL2 fallback, chosen per tier from `TierFeatures`.
- R-PLAT-05 (s): the iPhone 15 run at `mobile-low` keeps its frame budget with the new look.
- R-ENG-02: render objects (shadow passes included), triangles, texture and GPU memory and cold download stay within each tier's budget in `check:perf`.

## Scope in
- **Look config** `config/world/look.json` + `config/schemas/world-look.schema.json` (design values †, tuned in this session; a config edit, not code, changes them):

```ts
// packages/world/src/client/look/config.ts — S02 domain types, not a numbered contract
export type LookProfile = 'full' | 'lite' | 'min' | 'legacy';   // legacy = the M02b1/M02b2 materials, unchanged
export interface FacadeClass { floorM: number; groundFloorM: number; bayM: number; winW: number; winH: number; sillM: number;
  glassRatio: number; wallRoughness: number; palette: readonly string[] /* sRGB hex */ }
export interface LookFile {
  schema: 'world-look/1';
  tierProfile: Record<QualityTierId, LookProfile>;   // ultra, desktop: full · mobile: lite · mobile-low: min · xr-quest, xr-visionpro: legacy
  postLevelCap: 0 | 1 | 2 | 3;                         // 2 until the M11a1 governor raises it (DL-704)
  exposureBias: Record<QualityTierId, number>;         // multiplies SkyUniforms.uExposure
  casterRadiusM: Partial<Record<QualityTierId, number>>; // ≤ TierFeatures.shadows.distanceM; casters = L0 `buildings` objects only
  shadowsOff: readonly QualityTierId[];                // fallback switch, empty by default
  facade: Record<'ResLow' | 'ResMid' | 'Commercial' | 'Tower' | 'Industrial' | 'Civic', FacadeClass>;
  roof: Record<'flat' | 'gable' | 'hip', { albedo: string; roughness: number; pattern: 'membrane' | 'shingle' }>;
  ground: Record<string, { albedo: string; roughness: number; noise: number }>; // keyed by GroundClass name and road class
  water: { deep: string; shallow: string; waves: readonly [dirDeg: number, lengthM: number, amp: number, speed: number][] };
  sky: { turbidity: Record<WeatherPreset, number>; rayleigh: Record<WeatherPreset, number>; keyframeWeight: Record<WeatherPreset, number> };
  webgl2Unsupported: readonly PostNode[];              // gtao-half, bloom or fsr1 when they fail on the WebGL2 backend, each with a spec/03 §7 row; never tonemap or an AA node; empty by default
  webgl2AaFallback: Partial<Record<'traa' | 'smaa', 'smaa' | 'fxaa'>>; // AA substitution on the WebGL2 backend when the node fails there (traa → smaa, else fxaa; smaa → fxaa), each with a spec/03 §7 row; empty by default
}
```

- **Surface ids in the mesher** (`mesher.ts`, `lod-mesher.ts`, `mesh-types.ts`): every `MeshBuffers` gains `surf` (`Uint8x4` per vertex: surface id, palette index, kind/roof code, 0) and `buildings` objects gain `facade` (`Int16x4` per vertex: metres × 10 along the footprint perimeter from the ring's first vertex, height above base, wall height, `seed & 0x7fff`). Surface ids are a table in `look/surfaces.ts`: the 12 `GroundClass` values, the 5 road classes, sidewalk, wall per `BuildingKind`, roof flat/gable/hip, parapet, rooftop equipment, trunk, leaves, L1/L2 massing, sea. `meshBytes` and `transferListOf` count the new arrays (+12 B per building vertex, +4 B per other vertex); outputs stay byte-identical across runs. Vertex colours stay (the `legacy` profile and the L1/L2 objects use them).
- **Materials** (`packages/world/src/client/look/`, TSL `*NodeMaterial` only; one material per object kind and profile, so pipelines stay few):
  - `facade.ts`: walls. Floor index `floor(v / floorM)`, bay `fract(u / bayM)` with ±15 % bay width from `seed`; window cells by `winW`, `winH`, `sillM`; a taller ground-floor band on Commercial, Tower and Civic (shop glass); a parapet band without windows; Tower uses `glassRatio` as a curtain wall with mullions; Industrial has few large openings. Wall albedo from the class palette crossed with the bake `palette` index; roughness per class; glass is dark, low roughness and reflects the environment on `full`, a Fresnel tint toward `uSkyBottom` on `lite`. Night: the per-building on/off decision and the blackout factor stay M02b2's `night.ts` rule (called, not copied); inside a lit building a per-window hash keeps 55–85 % † of cells lit; emissive goes to bloom on desktop. A `setFacadeAtlas(texture | null)` input (unused here) is the hook M10d2's `chunks/facade.ts` fills on desktop tiers.
  - `roof.ts`: flat roofs a light membrane with seams, gable and hip roofs shingle courses along the slope; parapets and rooftop equipment their own roughness.
  - `ground.ts`: asphalt (dark, value noise, roughness 0.85 †), sidewalk (concrete with a 1.5 m slab joint grid from world `xz`), park and grass (two-scale colour noise), sand, dirt, rock, pier planks, rail ballast. Wetness and its per-tier form (albedo, or albedo and roughness) come from M02b2's `tiers.ts` and `uWet`, never redefined.
  - `water.ts`: `Water` and `WaterShallow` cells of the terrain, the L1/L2 water sheets and the backdrop sea. Fragment-only waves (sum of the `water.waves` directional sines on the normal; no vertex displacement, so physics and meshes are unchanged): 4 waves with environment reflection and a sun glint on `full`, 2 waves and a sky-colour Fresnel on `lite`, a flat colour on `min`.
  - `noise.ts`: TSL hash and value-noise helpers; every pattern is computed, so this milestone adds no image file and no texture download.
  - `min` profile (`mobile-low`): vertex colour with class roughness by day (`02-world-bake.md` §6 "vertex colour only"), the window grid only as the night emissive mask; no waves.
  - L1/L2 coarse objects keep M02b1's world-space night mask with the new palettes; the cover mask and the dithered fade are unchanged.
- **Sky and sun** (`look/sky-physical.ts`, `look/sun.ts`):
  - `sun.ts` (pure, Node-testable): `sunState(env: SkyUniforms, preset, look)` → sun colour and intensity from M02b2's `uSunDir` through an air-mass and turbidity model, moon light at night from M02b2's rule, `exposure = uExposure × exposureBias[tier]`. Every flat tier lights with it, so `mobile` matches desktop without the per-pixel sky.
  - `full` only: a physically based day sky behind the M02b2 dome: `SkyMesh` (`three/addons/objects/SkyMesh.js`, TSL, WebGPURenderer only; spec/03 §7, DL-704) driven by `uSunDir`, `turbidity`, `rayleigh` per preset and `cloudCover` from the sky keys; the M02b2 dome keeps stars, moon and night and is blended over it with `w = max(uNight, keyframeWeight[preset])` (fog, overcast, rain and smoke stay close to the authored keys). Fallback if `SkyMesh` cannot be composed this way: an original Preetham-model TSL `Fn` in the same file.
  - Environment on `full`: a `PMREMGenerator` (from `three/webgpu`) map of the sky scene, re-generated only under M02b2's probe rule (sun > 0.006 rad, darkness > 0.04, at most every 200 ms). This re-bake is the one offscreen render allowed beside the `11-platform.md` §5.7 rule (one `RenderPipeline.render()` per frame, WebKit bug 303203 mitigation), bounded by that cadence and never on WebKit: with `DeviceProfile.browser === 'safari'` the `full` profile uses the hemisphere fallback (`envMap: false`) (DL-704). Fallback elsewhere: hemisphere light only. Either way the observed result (backend, browser, re-bake ms) is a spec/03 §7 row.
  - Tone mapping stays `NeutralToneMapping` (`11-platform.md` §5.1), applied exactly once, in the pipeline output; `toneMappingExposure` follows `sunState`.
- **Shadows** (`look/shadows.ts`) from `TierFeatures.shadows`: `csm3` on desktop tiers through `CSMShadowNode` (`three/addons/csm/CSMShadowNode.js`, `cascades: 3`, its verified default, and `maxFar` = `distanceM`) on a `DirectionalLight` with the tier's map size per cascade; `csm1` on `mobile` as one `DirectionalLight` shadow of `mapSize` fitted to `distanceM` around the player; `blob` on `mobile-low` (no shadow map; no dynamic actor needs a blob yet). Casters are the L0 `buildings` objects of chunks within `casterRadiusM` at upload time (re-decided only on M02b1's existing LOD-swap re-record, never adding a re-record); terrain, roads and vegetation only receive. `shadowPasses` is the cascade count the active shadow object reports (3 with `CSMShadowNode`, 1 for `csm1` or a fitted cascade, 0 for `blob`, `shadowsOff` and `legacy`), never a constant per mode; both `RenderBudgetMeter.measure` callers pass it (the `check:perf` scenario runner and the live meter), so shadow work is inside the counted budget. Fallbacks in order: `SunLight` (`three/addons/lights/SunLight.js`: two fixed cascades in one 2 × 1 atlas, spec/03 §7, so it reports 2 and AC-5 expects 2; registered with `renderer.library.addLight(SunLightNode, SunLight)` and re-registered on renderer replacement; on `desktop-ultra` the atlas is 8192 × 4096; if the adapter rejects that size, the map drops to 2048 per cascade and the report says so), then one fitted `DirectionalLight` cascade on desktop (reports 1).
- **Post stack** (`packages/engine/src/platform/post/`; engine platform, because `PostNode` is C13):
  - `levels.ts` (pure): `postNodes(features, postLevel, cap)` → ordered node list. Level 2 = `post`; 1 = level 2 without `gtao-half`; 0 = level 1 without `bloom`, with `traa`/`smaa` replaced by `fxaa` (research knob order: GTAO, then bloom, then AA mode [research/stack-rendering-platform.md §6.4]); 3 = level 2 plus `optionalPost`, where an optional AA node replaces the tier's AA node (never a second AA node), other optional nodes go before `tonemap`, and `fsr1` goes last (it upscales the final image). The lists AC-2 asserts, per level 3/2/1/0: ultra `[gtao-half, bloom, traa, tonemap, fsr1]` / `[gtao-half, bloom, traa, tonemap]` / `[bloom, traa, tonemap]` / `[fxaa, tonemap]`; desktop `[gtao-half, bloom, traa, tonemap]` / `[gtao-half, bloom, smaa, tonemap]` / `[bloom, smaa, tonemap]` / `[fxaa, tonemap]`; mobile `[bloom, fxaa, tonemap]` / `[fxaa, tonemap]` / `[fxaa, tonemap]` / `[fxaa, tonemap]`; mobile-low `[tonemap]` at every level. The effective level is `min(dynamic.postLevel, postLevelCap)`; with the cap at 2 the tier's `post` list is exactly what runs. XR (`pipeline: 'direct'`) returns `[]`. These level semantics are the ones M11a1's governor drives.
  - `nodes.ts`: one factory per `PostNode` from the verified `three/addons/tsl/display/` exports (`ao` from GTAONode at half resolution with `pass` + `mrt` depth and view normals, `bloom`, `smaa`, `fxaa`, `traa` with the velocity output, `fsr1`), and `RenderPipeline` from `three/webgpu` (spec/03 §7, DL-704). On the WebGL2 backend only: a node in `look.json` `webgl2Unsupported` is skipped, and an AA node in `webgl2AaFallback` is replaced by its substitute.
  - `stack.ts`: `PostStack` built from the node list for the current tier, rebuilt on tier change, on a `postLevel` change and in `onRendererReplaced`. The M02b1 backdrop pass and the world pass render into one colour target (backdrop first, the world pass clears depth only); GTAO reads only the world depth (backdrop pixels keep AO 1). A list that is only `tonemap` renders straight to the canvas with tone mapping in the material output (no intermediate target, cheapest on `mobile-low`). `RendererHost` renders through the stack when `features.pipeline === 'render-pipeline'` and the look is on; the XR direct path is untouched.
- **Switch, QA and bridge:** `config/platform-flags.json` key `world.look` (default `true`), typed and read in `packages/engine/src/platform/tier-config.ts` like `world.cards` (DL-698). `false` is a full rollback switch: `legacy` materials on every tier and the M01c renderer state (no post stack, no shadow map, M01c tone mapping and exposure only), so the "before" image is the pre-M02e look. `__dvBridge.world.look()` reports `{ profile, postNodes, shadowMode: ShadowMode | 'none', shadowPasses, casters, exposure, envMap: boolean, sky: 'physical' | 'dome', windowEmissive }` (`legacy` reports `postNodes: []`, `shadowMode: 'none'`, `shadowPasses: 0`; `windowEmissive` is the façade material's night-emissive uniform, 0 by day); `__dvBridge.world.setLook(on)` swaps materials and adds or removes the stack and shadows at runtime in QA builds (one re-record per resident chunk) for the before/after capture; `__dvBridge.world.shot(id)` applies a shot from `config/world/look-shots.json` (`{ id, x, y, z, yawDeg, pitchDeg, fovDeg, hour, weather }`): pauses the sim, locks hour and weather with a zero-second blend through M02b2's `setHour`/`setWeather` (M02b2's luma helper is not used for capture), freezes the look clock (waves, `SkyMesh` cloud motion), holds the camera (M01b2 debug free camera or a host override; a `BD-NNN` row), waits for `settle()` and the fade, renders the frames the stack needs inside the normal frame loop and resolves once the frame is presented. The spec then captures the post-stack output as a Playwright element screenshot of the canvas at a 256 × 144 viewport (device scale 1); no extra offscreen render is added. Debug panel (`?debug=1`): a look toggle and the active node list.
- **Goldens:** shots `noon-street` (13:00 `clear`), `golden-water` (19:00 `golden`), `night-street` (22:00 `clear`) at `desktop`, `mobile` and `mobile-low`, plus `fog-west` (09:00 `karl-fog`) at `desktop`: 10 PNGs at 256 × 144 in `tests/e2e/golden/look/<tier>.<shot>.png` with `tests/e2e/golden/look/manifest.json` (source synth `bakeId`, viewport, tolerance). Compare: per channel |Δ| ≤ 6/255 on ≥ 99 % of pixels and mean |Δ| ≤ 2/255 (`tests/support/image-diff.ts`, pure, decoding and encoding PNG with `pngjs`, already a root devDependency). A different synth `bakeId` fails with `look golden from bake <old>, current bake <new>`; regeneration only with `DV_UPDATE_GOLDEN=1` outside CI, under the `golden-update` label (M00d `golden-guard`, `**/golden/**`; DL-657 pattern).
- **Before/after:** `@look-compare` with `DV_LOOK_WRITE=1` captures `noon-street` and `night-street` at `?tier=desktop` with `setLook(false)` then `setLook(true)` as canvas element screenshots at a 960 × 540 viewport, composes them with `pngjs` into `docs/look/M02e-before-after.png` (1920 × 1080: rows noon, night; columns before, after) and writes `docs/look/M02e-before-after.json` (`commit`, `bakeId`, `tier`, `backend`, shots, `sha256` of the PNG, mean absolute difference per shot). Without the variable it checks the committed pair.
- **Perf and device runs:** no new scenario; `walk-civic-center` and `route-ferry-ocean-beach` run with the look on. Checklists `tools/ci/checklists/M02e-iphone15.json` (operator-built `DV_WORLD=synth` Preview, `mobile-low`, `walk-civic-center` at 21:30 `clear`, look on then off through the debug panel) and `tools/ci/checklists/M02e-mac.json` (`route-ferry-ocean-beach` at `desktop` on the operator's `sf` bake; per post node and for the shadow pass, GPU ms if `trackTimestamp` resolves, otherwise CPU frame-time deltas from toggling each node off in the debug panel; informational, never a pass condition).

## Risks & fallbacks
- **A post node fails on the WebGL2 backend:** `gtao-half`, `bloom` or `fsr1` go into `look.json` `webgl2Unsupported` with a spec/03 §7 row (observed error, date); the stack skips them there and AC-5 subtracts them. A failing `traa` or `smaa` goes into `webgl2AaFallback` (`traa` → `smaa`, else `fxaa`; `smaa` → `fxaa`) with a spec/03 §7 row, and AC-5 expects the substitute. Only a failing `tonemap` or `fxaa` stops the session (report, Blocked on the Architect).
- **`CSMShadowNode` unusable:** `SunLight` (2 cascades, `shadowPasses` 2), then one fitted `DirectionalLight` cascade on desktop (1); report it.
- **Render objects over budget with shadows:** lower `casterRadiusM` (data), then cast only from the focus chunk and its 8 neighbours; never raise a budget. **Mobile shadow too costly on the iPhone (AC-12):** add `mobile` to `shadowsOff` (data) and record it.
- **Upload cap breach on `mobile-low`:** drop `facade` on the `min` profile (the night mask falls back to M02b1's world grid).
- **Goldens flaky under SwiftShader:** keep the tolerance; if still flaky, move `@look-golden` to nightly and assert the analytic `sunState` values and bridge state in the PR suite (log the decision).
