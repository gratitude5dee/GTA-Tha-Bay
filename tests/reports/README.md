# tests/reports

Generated by the spec gates (M00d); git-ignored except this file. `pnpm check:unit -- tools/ci` regenerates them.

| File | Written by | Content |
|---|---|---|
| `milestones.json` | `tools/ci/milestone-lint.ts` (`milestone-format.test.ts`) | `{file, status, enforced, errors[], warnings[]}` per milestone file; PENDING files carry their findings as warnings |
| `trace.json`, `trace.md` | `tools/ci/trace.ts` (`traceability.test.ts`) | R-ID to spec sections, milestones, test names and status (`blocked (Q-NN)`, `seen-on-device`, `tested`, `ready`, `planned`, `post-gate`) with `empty` and `device-only` flags; `trace.md` is the table `spec/01-product.md` section 13 copies |
| `spec-files.json` | `tools/ci/spec-files.ts` (`spec-files.test.ts`) | findings and warnings of the Definition-of-Done checks; fails only with `--strict` (M14b3) |

The Vitest and Playwright JSON reports of the `main` run also land here in CI (job `unit` uploads this directory); `trace.ts --results <dir>` reads them to decide which rows are `tested`.
